# GPT Image 2 production prompts

The landing page currently uses its token-driven CSS fallback because `OPENAI_API_KEY` was not
configured during implementation. Generate these assets with the approved GPT Image 2 CLI workflow,
inspect them, and save selected outputs alongside this file.

## Hero editorial collage — `hero-editorial-collage.webp`

```text
Use case: ads-marketing
Asset type: Impactional youth-organization landing page hero atmosphere
Primary request: Create an abstract editorial collage about young ideas traveling across borders.
Scene/backdrop: layered off-white paper, ink fields, cartographic contour lines, orbital paths,
punched paper circles, registration marks, and subtle photocopied texture.
Style/medium: premium contemporary magazine collage, tactile printmaking, precise but energetic.
Composition/framing: 2048x1152 landscape; keep the left 48% quiet for HTML headline copy; build the
main visual energy through the center-right and preserve clean crop options at mobile ratios.
Color palette: #141414 ink, #E01483 magenta, #E6AA33 amber, #007DBB ocean, #1CCEA4 mint,
and #F6F1E9 canvas.
Constraints: abstract only; no people presented as documentary participants; no logos; no flags;
no partner marks; no letters, words, numbers, watermarks, or UI elements.
Avoid: glossy 3D, generic corporate gradients, sci-fi interfaces, legible map labels, fake text.
```

## Reusable square texture — `editorial-texture-square.webp`

```text
Use case: ads-marketing
Asset type: reusable section texture for the Impactional landing page
Primary request: Create a seamless-feeling square editorial texture expressing ripples becoming
connected paths.
Scene/backdrop: rough paper fibers, offset ink, curved orbit fragments, small hand-cut geometric
pieces, and faint cartographic line work.
Style/medium: restrained screen print and risograph collage with generous negative space.
Composition/framing: 2048x2048 square, balanced edge-to-edge so it can be cropped responsively.
Color palette: #141414, #E01483, #E6AA33, #007DBB, #1CCEA4, #F6F1E9.
Constraints: no text, logos, people, flags, partner marks, or watermarks.
Avoid: photorealism, shiny surfaces, gradients that resemble generic AI artwork.
```
